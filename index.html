Hoe werkt deze site?

De site is gehost op GitHub Pages. Alles wat je invult, sla je op als een JSON-bestand per persoon in de repo. Zo ziet iedereen elkaars voortgang.
  1. Kies je naam en open een fase.
  2. Schrijf wat je hebt gedaan en voeg eventueel foto's en/of pdf's toe (een pdf mag maximaal 2 MB zijn). Kan een andere laptop zijn: je werk wordt hier automatisch lokaal bewaard.
  3. Klaar? Klik "Publiceren". Er wordt een bestand gedownload, bijvoorbeeld thijn.json.
  4. Ga naar de GitHub-repo en vervang daarmee data/thijn.json (of tijmen/marten).
  5. Iedereen die de site opent, ziet nu jouw gepubliceerde voortgang.
Ben je op een andere computer? Klik "Importeer bestand" en kies jouw gecommitte JSON om verder te werken.
